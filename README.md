# ➕➖ CalcuJ - Sua Calculadora Simples em Java

Bem-vindo ao **CalcuJ**, uma calculadora de linha de comando simples desenvolvida em **Java**, com testes de unidade robustos usando **JUnit5**. Este projeto demonstra uma aplicação básica de console que realiza operações aritméticas fundamentais.

### ✨ Funcionalidade Principal

O **CalcuJ** permite que o usuário realize operações de soma, subtração, multiplicação e divisão entre dois números inteiros. A interação ocorre diretamente no terminal, tornando-o uma ferramenta prática e direta para cálculos rápidos.

---

## 🚀 Como Rodar o Projeto

Para executar esta calculadora em sua máquina, siga os passos abaixo:

### Pré-requisitos

* **Java Development Kit (JDK)**: Versão 8 ou superior. Baixe em [oracle.com/java](https://www.oracle.com/java/technologies/downloads/).
* **JUnit 5 (Opcional, para rodar os testes)**: Se estiver usando Maven ou Gradle, as dependências serão gerenciadas automaticamente. Caso contrário, você precisará adicionar as JARs do JUnit 5 ao seu `classpath`.

### Estrutura do Projeto (Exemplo)

Certifique-se de que seus arquivos `Main.java` e `Calculadora.java` (e `CalculadoraTest.java` para os testes) estejam na mesma pasta ou configurados corretamente em um projeto Java (ex: Maven/Gradle).
